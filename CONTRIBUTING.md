# Contributing

Jev Lab is a source-linked directory and experiment map. Contributions can add an independent project, correct a description, reproduce a result or identify a boundary that a repository does not state clearly enough.

For a project submission, include:

- a public repository;
- a one-sentence description of the decision task;
- a runnable example or honest explanation of what is not runnable yet;
- the distinction between synthetic fixtures and live model results;
- a license and security/contact information appropriate to the project.

Projects do not need to use the same language, SDK or architecture. Marketing-only pages, unverifiable performance claims and repositories that expose credentials are not accepted.
